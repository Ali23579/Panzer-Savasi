# Panzer Savaşı (Tank Savaşı) - Unity

Unity oyun motoru ve C# kullanılarak geliştirilmiş basit bir tank savaşı oyunu projesi.

## 🕹️ Açıklama

Bu proje, oyuncunun bir tankı kontrol ederek düşman tanklarına (veya diğer oyunculara) karşı savaştığı temel bir tank oyunu mekaniğini içerir.

## ✨ Özellikler

* Tank hareketi (ileri, geri, dönme)
* Tank topu (nişan alma ve ateş etme)
* Mermi fiziği ve çarpışma algılama
* (Varsa ek özelliklerini buraya listele, örn: Düşman yapay zekası, can sistemi, farklı tank modelleri, harita engelleri vb.)

## 💻 Kullanılan Teknolojiler

* Oyun Motoru: Unity (Kullandığın sürümü belirtebilirsin, örn: 202X.X.X)
* Programlama Dili: C#

## 🚀 Kurulum

1.  Bu repoyu bilgisayarınıza klonlayın veya ZIP olarak indirin.
    ```bash
    git clone [https://github.com/Ali23579/Panzer-Savasi.git](https://github.com/Ali23579/Panzer-Savasi.git)
    ```
2.  Unity Hub'ı açın.
3.  "Add" veya "Open" seçeneği ile indirmiş olduğunuz proje klasörünü Unity'ye ekleyin.
4.  Projenin Unity editöründe açılmasını bekleyin.

## ▶️ Kullanım

1.  Unity Editöründe `Assets/Scenes` (veya ana sahnenin bulunduğu klasör) içerisindeki ana oyun sahnesini (`.unity` uzantılı dosya) açın.
2.  Editörün üst kısmındaki "Play" (▶️) düğmesine tıklayarak oyunu başlatın.
3.  (Varsa oyun kontrollerini buraya ekle, örn: WASD = Hareket, Fare = Nişan Alma, Sol Tık = Ateş)
